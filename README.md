# Doom Ore (Fabric 1.20.1)

Adds Doom Ore (overworld, Y -64 to 16), Deepslate Doom Ore, Raw Doom, Doom Ingot,
Block of Doom, Block of Raw Doom, and Doom Sword / Pickaxe / Axe / Shovel / Hoe.

Requires: Minecraft 1.20.1, Fabric Loader 0.15+, Fabric API 0.92.2+1.20.1.

Build: push to GitHub, open the Actions tab, download the `doomore-mod` artifact.
Locally: `gradle build` (Java 17), jar appears in `build/libs/`.
